# Zemu loader

2 s seamless loop, 60 fps (120 frames). Frame 120 == frame 0, so loop it; don't add a closing frame.

| File | Use on |
|---|---|
| `zemu-loader.json` | Lottie: Android (`com.airbnb.android:lottie`), iOS/macOS (`lottie-ios`), web (`lottie-web`) |
| `roku/images/loader/00–59.png` | Roku: 30 fps, 256 px frames, played by `roku/components/widgets/ZemuLoader` (`frames/` here is the 60 fps source, regenerated by the build) |
| `zemu-loader.apng` | Transparent animated image for web/docs |
| `zemu-loader-preview.gif` | Transparent preview (GIF edges are hard; use the APNG or Lottie for real UI) |

Edit timing/sizes in `build.mjs`, then `npm install && node build.mjs` (needs ffmpeg).
