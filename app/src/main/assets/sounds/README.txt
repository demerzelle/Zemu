ZEMU SOUND EFFECTS — where to put your own sounds
=================================================

Each folder is a theme. Each file is one action:

  move.wav     the remote's arrow keys (moving between buttons, posters, rows)
  select.wav   pressing OK / tapping something
  hold.wav     holding OK (long press: options, row editor, track picker)
  back.wav     the Back button

Folders (which theme uses them):

  default/     every theme without its own folder (Off, RGB, Weather, Holidays, Cyberpunk, ...)
  ps2/         PS2 · Y2K
  acidwave/    Acidwave
  cybercore/   Cybercore (Classic, Kawaii and XP)
  graffiti/    Graffiti
  liquid/      Liquid Glass
  ethereal/    Ethereal · Aurora
  catrave/     the secret Cat Rave
  toddler/     Kids Mode · Toddler
  gradeschool/ Kids Mode · Grade School
  youngadult/  Kids Mode · Young Adult
  pocket/      Pocket LCD (handheld)
  sixteen/     16-Bit (console)

The .wav files here are placeholders. To use your own, drop a file with the same name in the
same folder — move.ogg, move.mp3, move.m4a or move.wav. If both exist, .ogg, .mp3 and .m4a win
over the .wav placeholder, so you don't have to delete it. If a theme folder is missing a file,
the one from default/ plays.

Keep them short (under about 1 second) and not too loud. After adding files, rebuild and
install the app. Sound effects can be turned off in Settings → Appearance → Sound effects.
